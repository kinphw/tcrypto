청라더헤븐 · 서길원 거래소 · 참여자용

진짜 이더리움 시험망에서 원화코인으로 사고팔기

청라더헤븐은 이더리움 공식 시험망(세폴리아) 위의 원화 스테이블코인 서길원(sgw) 거래소입니다. 순서는 지갑 만들기 → 입금 신청 → 사용 → 환매 신청 네 단계뿐입니다. ETH(수수료)가 없어도 됩니다 — 서명만 하면 발행자가 수수료를 대신 냅니다. 준비는 5분이면 됩니다.

모든 코인과 상품은 가상이며 가치가 없습니다. 세폴리아는 전 세계에 공개된 블록체인이라 송금 메모·상품 사진을 누구나 볼 수 있고, 아무도 지울 수 없습니다. 실명과 연락처는 넣지 마세요.

  1. 지갑 만들기

    • 휴대폰: 앱스토어·플레이스토어에서 MetaMask 앱 설치 → 새 지갑 만들기
    • PC: 크롬에서 metamask.io/download → 확장 프로그램 설치 → 새 지갑 만들기

    화면에 나오는 비밀 복구 구문 12단어를 종이에 적어 두세요. 이 12단어가 지갑의 전부입니다. 누구에게도 알려주지 마세요.

    거래소 열기

    • 휴대폰: MetaMask 앱 → 아래쪽 탐색(돋보기, 버전에 따라 ‘브라우저’) → 위쪽 검색창에 kinphw.github.io/tcrypto 입력. 한 번 열면 방문 기록에 남아요.
    • PC: 크롬에서 kinphw.github.io/tcrypto

    MetaMask 연결 → 승인. 네트워크를 Sepolia 로 바꾸라고 하면 바꿉니다.

    왜 MetaMask 앱 안에서? 사파리·크롬·카톡 같은 일반 인터넷 창에는 지갑이 없어서 서명을 할 수 없어요. (보기만 하는 건 어디서든 됩니다) 바로 열기 링크도 있지만 폰에 따라 안 될 수 있어요: link.metamask.io/dapp/kinphw.github.io/tcrypto

  2. 입금 신청 — 원화 → 서길원

    1. 내 지갑 → 입금 신청에 금액을 넣고 누르기
    2. MetaMask 에 서명 요청이 뜹니다. 거래가 아니라 서명이라 수수료 0 → 서명
    3. “요청을 보냈습니다”가 뜨면 끝. 발행사의 자동 처리기가 확인하고 보통 1분 안에 서길원이 들어옵니다

    실제 스테이블코인도 같습니다: 은행에 원화가 들어온 걸 발행사가 확인해야 코인을 찍어 줍니다. 입금 확인은 블록체인 밖의 일이라 코드가 대신할 수 없습니다. (이 실험실에선 실제 입금은 안 해도 됩니다)

  3. 사용

    • 송금: 받는 사람 주소로 보냅니다.
    • 상점가: 상품을 고르고 구매하기 → 서명. 처리되는 순간 재고가 줄고 서길원이 상점 주인에게 옮겨집니다.
    • 내 상점: 상점을 열고 사진과 함께 상품을 올립니다. 팔리면 서길원이 바로 들어옵니다.
    • 내 코인 만들기: 나만의 코인(예: 철수포인트)을 만들어 나눠 줄 수 있습니다.
    • 들여다보기: 모든 거래를 눌러 서명·수수료·실행 내용과 블록체인 원본 데이터를 직접 확인합니다.

    수수료는? 여러분은 서길원만 있으면 됩니다. 무엇을 하든 MetaMask 로 서명만 하면, 발행사의 자동 처리기가 수수료(ETH)를 내고 블록체인에 올립니다. 보통 1분 안에 반영됩니다. 실제 USDC 앱의 ‘수수료 없는 송금’과 같은 구조입니다.

  4. 환매 신청 — 서길원 → 원화

    내 지갑 → 환매 신청에 금액을 넣으면 서길원이 발행사로 돌아갑니다. 발행사는 원화를 돌려주고(블록체인 밖) 받은 서길원을 소각합니다.

    정리하면 입금 → 발행 → 자유롭게 사용 → 환매 → 소각. 실제 원화 스테이블코인과 같은 한 바퀴입니다.

요청함 — 서명이 어디로 가나

서명한 요청은 화면이 공개 우편함(ntfy.sh)에 넣고, 발행사의 자동 처리기가 꺼내서 서명을 검증한 뒤 수수료를 내고 블록체인에 올립니다. 입금 신청은 자동 처리기가 정해진 한도 안에서 발행하고, 큰 금액은 발행자가 직접 확인합니다. 메뉴의 요청함에서 대기 중·처리된 요청, 걸러 낸 위조 요청, 우편함 원문까지 누구나 볼 수 있습니다.

실제 USDC 와 비교: USDC 앱에서 ‘수수료 없이 보내기’를 누르면 앱이 서명을 회사 서버(릴레이어)로 보내고, 서버가 수수료를 내고 올립니다. 그 서버는 밖에서 안 보입니다. 청라더헤븐은 그 서버 자리를 누구나 들여다볼 수 있는 공개 우편함으로 바꿨습니다. 그래서 중개자가 요청을 묵히거나 빼먹는지도 모두가 확인할 수 있습니다.

문제가 생기면

증상해결
‘MetaMask 설치 필요’가 계속 보임PC는 크롬에 확장 프로그램이 켜져 있는지, 휴대폰은 MetaMask 앱 안(탐색)에서 열었는지 확인하세요.
‘트랜잭션 실패’ (확인 창에 ‘스마트 계정’ 문구)MetaMask 의 스마트 계정 기능 때문입니다. MetaMask 설정 → 스마트 계정 → Sepolia 스위치를 끄고 다시 하세요.
‘Sepolia 로 전환’ 버튼이 보임버튼을 누르거나 MetaMask 에서 직접 Sepolia 를 고르세요.
‘insufficient funds’ 오류수수료 방식이 ‘내가 냄’인데 SepoliaETH 가 없습니다. 내 지갑 → 수수료 설정에서 ‘발행자가 냄’이나 ‘자동’으로 바꾸세요.
서명했는데 반영이 안 됨내 지갑 위쪽이나 요청함에서 내 요청이 ‘처리 대기’인지 보세요. 발행사의 자동 처리기가 꺼져 있으면(발행자 컴퓨터가 꺼짐 등) 켜질 때 처리됩니다. 요청함은 12시간 보관이라, 그 안에 처리되지 않으면 다시 서명하면 됩니다.
‘요청함에 넣지 못했습니다’우편함 서비스가 잠시 안 되는 것입니다. 나온 링크 복사로 링크를 발행자에게 카톡으로 보내세요.
‘순서 대기’ 또는 ‘이미 실행됐거나 … 무효’한 사람의 대납 요청은 순서대로 처리됩니다. 앞 요청이 처리되면 풀리고, 무효가 됐다면 다시 서명하세요.
거래가 ‘실패’컨트랙트가 거절한 것입니다(잔액 부족, 차단된 계좌, 전체 정지, 품절 등). 거래 해부 화면에서 이유를 보세요.
