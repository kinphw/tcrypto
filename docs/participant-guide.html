진짜 이더리움 시험망에서 원화코인으로 사고팔기

청라더헤븐은 이더리움 공식 시험망(세폴리아) 위의 원화 스테이블코인 서길원(sgw) 거래소입니다. 여러분은 MetaMask 지갑으로 들어와 입금 신고로 코인을 발행받고, 송금하고, 상점을 열어 사고팝니다. ETH(수수료)가 없어도 됩니다 — 서명만 하면 발행자가 수수료를 대신 냅니다. 준비는 10분이면 됩니다.

모든 코인과 상품은 가상이며 가치가 없습니다. 세폴리아는 전 세계에 공개된 블록체인이라 닉네임·송금 메모·상품 사진을 누구나 볼 수 있고, 아무도 지울 수 없습니다. 실명과 연락처는 넣지 마세요.

  1. MetaMask 지갑 만들기

    • PC: 크롬에서 metamask.io/download → 크롬 확장 프로그램 설치 → 새 지갑 만들기
    • 휴대폰: 앱스토어·플레이스토어에서 MetaMask 앱 설치 → 새 지갑 만들기

    화면에 나오는 비밀 복구 구문 12단어를 종이에 적어 두세요. 이 12단어가 지갑의 전부입니다. 누구에게도 알려주지 마세요.

  2. 세폴리아 시험망 켜기

    MetaMask 왼쪽 위 네트워크 선택 → 테스트 네트워크 보기 켜기 → Sepolia 선택.

    확인: MetaMask 위쪽에 Sepolia 가 보이면 됩니다. 거래소 사이트에 처음 들어가면 자동으로 바꿔 주기도 합니다.

  3. 거래소 링크 열고 연결하기

    • PC: 크롬에서 https://kinphw.github.io/tcrypto/ 를 엽니다.
    • 휴대폰: 이 링크를 누르세요 → link.metamask.io/dapp/kinphw.github.io/tcrypto
      MetaMask 앱이 열리고, 앱 안의 인터넷 창으로 거래소가 바로 뜹니다. (사파리·크롬 같은 일반 인터넷 앱에는 지갑이 없어 연결되지 않아요)
    • 카톡에서 눌렀는데 안 열리면: 카톡 안 브라우저는 다른 앱으로 넘기는 링크를 막을 때가 있어요. 링크를 길게 눌러 복사 → 크롬·사파리 주소창에 붙여넣어 열면 MetaMask 앱으로 넘어갑니다.
    • 가장 확실한 방법: MetaMask 앱을 직접 열고 아래쪽 탐색(돋보기) → 위쪽 검색창에 kinphw.github.io/tcrypto 입력. 앱 버전에 따라 이름이 ‘브라우저’일 수도 있어요. 한 번 열면 다음부터는 방문 기록에 남습니다.

    MetaMask 연결 → MetaMask 에서 승인.

    확인: 오른쪽 위 버튼이 내 주소로 바뀌면 연결된 것입니다. 이 사이트는 서버가 없는 화면일 뿐이고, 버튼을 누르면 내 MetaMask 가 블록체인에 직접 서명해 보냅니다.

  4. 닉네임 가입 — 서명만 하면 끝

    1. 내 지갑 화면에서 닉네임을 정하고 가입 (닉네임은 나중에 못 바꿉니다)
    2. MetaMask 에 서명 요청이 뜹니다. 거래가 아니라 서명이라 수수료가 없습니다 → 서명
    3. “요청을 보냈습니다”가 뜨면 끝. 서명이 공개 요청함에 자동으로 들어갑니다 (따로 연락할 필요 없음)
    4. 발행자가 요청함에서 보고 올려 주면 가입 완료. 진행 상황은 메뉴의 요청함에서 누구나 볼 수 있어요

    무슨 일이냐면: 블록체인에 기록하려면 ETH 수수료가 필요한데, 여러분은 “이걸 해 주세요”에 서명만 하고 발행자가 수수료를 내고 올립니다. 발행자는 내용을 바꿀 수 없습니다(바꾸면 서명이 깨짐). 실제 USDC 지갑의 ‘수수료 없는 송금’과 같은 구조입니다. 요청함이 안 될 때는 예비로 링크 복사가 나오니 그 링크를 발행자에게 보내면 됩니다.

  5. 입금 신고 → 서길원 받기

    1. 내 지갑 → 입금 신고에 금액과 메모(예: 입금자명)를 넣고 신고서 서명
    2. 신고서가 요청함으로 발행자에게 자동으로 갑니다
    3. 발행자가 입금을 확인하고 발행하면 서길원이 들어옵니다

    왜 이렇게 하냐면: 실제 스테이블코인도 은행에 원화가 들어온 걸 발행사가 확인해야 코인을 찍어 줍니다. 은행 입금 확인은 블록체인 밖의 일이라 코드가 대신할 수 없습니다. (이 실험실에선 실제 입금은 하지 않아도 됩니다)

  6. 놀기

    • 송금: 닉네임만 알면 보낼 수 있습니다.
    • 상점가: 상품을 고르고 구매하기 → 결제 서명(요청함으로 자동 전달). 발행자가 올리는 순간 재고가 줄고 서길원이 상점 주인에게 옮겨집니다.
    • 내 상점 관리: 상점을 열고 사진과 함께 상품을 올립니다. 팔리면 서길원이 바로 들어옵니다.
    • 내 코인 발행: 나만의 코인(예: 철수포인트)을 만들어 친구들에게 나눠 줄 수 있습니다.
    • 들여다보기: 모든 거래를 눌러 서명·수수료·실행 내용과 블록체인 원본 데이터를 직접 확인합니다.

    기다리지 않고 직접 하고 싶다면: 내 지갑 → 수수료용 ETH 요청하기를 누르면(서명만) 발행자가 ETH 를 보내 줍니다. 그다음부터는 수수료 방식 자동이 알아서 내가 냄으로 바뀌어, 발행자를 기다리지 않고 바로 블록체인에 올라갑니다. 직접 받으려면 Google Cloud 세폴리아 배급처에서 받으세요. 기본값 자동은 ETH 가 있으면 직접, 없으면 대납입니다.

  7. 요청함 — 어떻게 돌아가는지 보기

    서명한 요청은 화면이 공개 우편함(ntfy.sh)에 넣고, 발행자 화면이 꺼내서 서명을 검증한 뒤 수수료를 내고 블록체인에 올립니다. 메뉴의 요청함에서 대기 중·처리된 요청, 걸러 낸 위조 요청, 우편함 원문까지 모두 볼 수 있습니다.

    실제 USDC 와 비교: USDC 앱에서 ‘수수료 없이 보내기’를 누르면 앱이 서명을 회사 서버(릴레이어)로 보내고, 서버가 수수료를 내고 올립니다. 그 서버는 밖에서 안 보입니다. 청라더헤븐은 그 서버 자리를 누구나 들여다볼 수 있는 공개 우편함으로 바꿨습니다. 그래서 중개자가 요청을 묵히거나 빼먹는지도 모두가 확인할 수 있습니다.

  8. 상환 — 서길원을 원화로 돌려받기

    내 지갑 → 상환 요청에 금액을 넣으면 서길원이 발행사 주소로 갑니다. 발행사는 원화를 돌려주고(블록체인 밖) 받은 서길원을 소각합니다. 실제 USDC 의 상환과 같은 흐름입니다.

  9. 웹사이트 말고 다른 곳에서도 확인하기

    거래소 웹사이트공개 노드에 직접 물어서 보여줌
    MetaMask내 지갑 화면의 MetaMask 에 표시하기를 누르면 토큰 탭에 sgw 가 생깁니다
    이더스캔화면 곳곳의 이더스캔 ↗ 링크로 같은 거래를 외부에서 확인

    핵심: 세 곳 모두 같은 숫자가 나와야 정상입니다. 이 웹사이트가 사라져도 잔액과 기록은 블록체인에 그대로 남아 있습니다.

문제가 생기면

증상해결
‘MetaMask 설치 필요’가 계속 보임PC는 크롬에 확장 프로그램이 켜져 있는지, 휴대폰은 위의 MetaMask 앱 링크로 열었는지 확인하세요.
‘트랜잭션 실패’ (확인 창에 ‘스마트 계정’ 문구)MetaMask 의 스마트 계정 기능 때문입니다. MetaMask 설정 → 스마트 계정 → Sepolia 스위치를 끄고 다시 하세요.
‘Sepolia 로 전환’ 버튼이 보임버튼을 누르거나 MetaMask 에서 직접 Sepolia 를 고르세요.
‘insufficient funds’ 오류수수료 방식이 ‘내가 냄’인데 SepoliaETH 가 없습니다. ‘대납 요청’이나 ‘자동’으로 바꾸세요.
서명했는데 반영이 안 됨요청함에서 내 요청이 ‘처리 대기’인지 보세요. 발행자가 아직 처리하지 않은 것입니다. 요청함은 12시간 보관이라, 그 안에 처리되지 않으면 다시 서명하면 됩니다.
‘요청함에 넣지 못했습니다’우편함 서비스가 잠시 안 되는 것입니다. 나온 링크 복사로 링크를 발행자에게 카톡으로 보내세요.
‘순서 대기’ 또는 ‘이미 실행됐거나 … 무효’한 사람의 대납 요청은 순서대로 처리됩니다. 앞 요청이 처리되면 풀리고, 무효가 됐다면 다시 서명하세요.
거래가 ‘실패’컨트랙트가 거절한 것입니다(잔액 부족, 차단된 계좌, 전체 정지, 품절 등). 거래 해부 화면에서 이유를 보세요.
