# TCrypto 감독 실험실

이더리움 공식 시험망 **세폴리아(Sepolia)** 위에서 돌아가는 작은 경제 실험실입니다.

- **당신(창조자)** = 원화 스테이블코인 **발행자**
- **친구들** = 링크로 들어와서 MetaMask 지갑으로 참여
- 할 수 있는 것: 원화코인 충전·환불, 송금, 상점 열기·상품 올리기·구매, 내 코인 만들기, 모든 거래 들여다보기

모든 기록은 이 웹사이트가 아니라 **이더리움(세폴리아) 블록체인**에 남습니다.
그래서 같은 잔액과 거래를 **이 웹사이트 · MetaMask · 이더스캔** 세 곳에서 따로 확인할 수 있습니다.

---

## 창조자가 할 일 (처음 한 번)

### 1. MetaMask 설치
1. 크롬에서 <https://metamask.io/download/> → 확장 프로그램 추가 → **새 지갑 만들기**
2. 비밀 복구 구문 12단어를 **종이에 적어 보관** (이 지갑이 원화코인 발행 권한을 갖게 됩니다)
3. MetaMask 왼쪽 위 네트워크 선택 → **테스트 네트워크 보기** 켜기 → **Sepolia** 선택

### 2. 시험용 ETH 받기 (수수료용, 무료)
블록체인에 무엇을 기록하든 아주 적은 수수료가 듭니다. 세폴리아에서는 가치 없는 시험용 ETH 로 냅니다.
- <https://cloud.google.com/application/web3/faucet/ethereum/sepolia> (구글 계정 로그인 → MetaMask 주소 붙여넣기)
- 하루 0.05 ETH 정도면 친구들에게 나눠줘도 충분합니다.

### 3. 실험실 열기 (컨트랙트 배포)
1. 실험실 웹사이트 링크를 열고 오른쪽 위 **MetaMask 연결**
2. 왼쪽 메뉴 **발행자 · 감독** → **MetaMask 로 배포 시작** → MetaMask 승인 4번
3. 끝나면 Claude 에게 **“배포 끝났어”** 라고 말하기 → 다른 사람들도 쓸 수 있게 설정을 반영합니다

### 4. 친구 초대
1. 링크와 [참여자 안내서](docs/participant-guide.html)를 보냅니다
2. 친구가 주소를 보내오면 **발행자 · 감독 → 수수료용 ETH 나눠주기** 로 조금씩 보냅니다 (0.01 이면 수백 번 거래 가능)
3. 친구들의 **충전 요청**을 **발행자 · 감독** 화면에서 승인하면 원화코인이 발행됩니다

## 화면 구성

| 메뉴 | 내용 |
|---|---|
| 내 지갑 | 가입(닉네임), 원화코인·ETH 잔액, 충전 요청, 환불 요청, 내 입출금 |
| 송금 | 닉네임으로 원화코인·친구 코인 보내기 (메모 포함) |
| 상점가 | 상품 구경·구매, 내 상점 열기, 상품 올리기(사진 포함), 받은 주문 |
| 내 코인 발행 | 누구나 자기 코인 만들기, 추가 발행 |
| 발행자 · 감독 | 요청 승인·거절, 직접 발행, 준비금 공시, 동결·강제소각·전체 정지, 권한 관리, 보유 현황, 감사 로그 |
| 들여다보기 | 실험실 전체 기록, 거래 해부(서명·수수료·실행 내용), 블록 해부, 주소 조회, 이더스캔 대조 |

## 폴더 구조 (개발용)

```
contracts\    스마트컨트랙트 소스 (Members, WonCoin, Market, CoinFactory)
web\          웹사이트 (빌드 과정 없는 순수 HTML/JS) — 이 폴더가 GitHub Pages 로 공개됨
  app-config.json   네트워크와 배포된 컨트랙트 주소
  contracts\        컴파일 결과 (ABI·기계어·소스)
tools-js\     컴파일·배포 탐지·로컬 미리보기 도구
docs\         참여자 안내서, 확장 가이드
```

```powershell
npm run compile                          # contracts\*.sol → web\contracts\*.json
npm run serve                            # http://localhost:8080 에서 미리보기
npm run find-deployment -- 0x발행자주소   # 배포된 컨트랙트 주소를 찾아 app-config.json 에 기록
```

새 기능을 붙이는 방법은 [docs/EXTENDING.md](docs/EXTENDING.md).

## 알아둘 점
- 세폴리아는 **전 세계에 공개된** 블록체인입니다. 닉네임·송금 메모·상품 사진을 누구나 볼 수 있습니다. 실명·연락처는 넣지 마세요.
- 코인과 상품은 모두 가상이며 가치가 없습니다. 외부 판매·홍보를 하지 않습니다.
- 한 번 배포한 컨트랙트 규칙은 고칠 수 없습니다. 규칙을 바꾸려면 새로 배포해야 하고, 기존 잔액은 옮겨지지 않습니다.
